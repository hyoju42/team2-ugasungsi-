# 🍊 제주 감귤 도매시장 AI 가격 & 거래량 예측 시스템 (Streamlit)

이 프로젝트는 최신 수정된 `경매only.csv`와 `정가수의only.csv` 데이터셋 및 `LightBGM경매예측.ipynb`, `LightBGM정가수의예측.ipynb` 노트북을 바탕으로 구축된 **제주 감귤 경매 및 정가수의 AI 가격·거래량 분석 및 당일 기준 향후 7일 단기 예측 Streamlit 대시보드**입니다.

---

## 🚀 빠른 시작 가이드 (실행 방법)

터미널(또는 명령 프롬프트 / PowerShell)에서 다음 명령어를 실행하여 웹 애플리케이션을 시작할 수 있습니다:

```bash
streamlit run app.py
```

브라우저가 자동으로 열리며, 열리지 않을 경우 `http://localhost:8501`로 접속하시면 됩니다.

---

## 📌 주요 반영 내역

### 1. 🎯 거래량 예측에 품목·크기별 예측 가격(price_feature) 직접 투입 연계
- 거래량 예측 모델에 **선택된 품목과 크기(규격)별로 달리 예측된 가격 값(`price_feature`)**과 전일 가격(`price_lag_1`)이 핵심 설명변수로 직접 투입됩니다.
- 1단계에서 각 품목 및 크기별 고유한 가격 추세와 기상/대체재 영향을 반영하여 일별 평균가격을 정밀 예측하고,
- 2단계에서 이 예측된 가격 값을 거래량 모델의 수요·공급 피처로 연계하여 해당 품목의 일별 총출하량을 최종 예측합니다.

### 2. 📅 월별 전체 거래량 중 품종별 점유율 (%) 분석 신규 탑재
- 사용자 요청에 따라 **거래량 피처 순위(Feature Importance)는 제외**하고,
- **1월부터 12월까지 전체 거래량 중 각 품종(노지온주, 만감류, 하우스감귤, 비가림감귤)이 몇 %를 차지하는지**를 시각화하는 **100% 누적 막대 차트**와 **상세 점유율 표**를 탑재했습니다.
- 어떤 품목/규격을 선택하고 실행하든 '경매 예측' 탭과 '시장 통계' 탭에서 월별 출하 점유율을 실시간으로 확인할 수 있습니다.

### 3. 🕒 실행 당일 날짜 기준 실시간 동적 7일 예측
- 하드코딩된 날짜 대신, **앱을 실행하는 시점의 실제 당일 날짜(오늘, D-Day)**를 실시간 자동 감지하여 앞으로 7일간(D+1 ~ D+7)의 예측치를 동적으로 산출합니다.
- 일요일 도매시장 정기 휴일 자동 0 물량 보정 및 휴일 배지 반영.

## 📁 프로젝트 파일 구성

```
LightBGM/
├── app.py                      # Streamlit 대시보드 메인 화면 (월별 점유율 및 고정 거래량 UI 반영)
├── pipeline.py                 # 품목 전체 거래량 독립 모델, 규격별 가격 연계 모델, 월별 점유율 연산 엔진
├── utils.py                    # Plotly 반응형 100% 누적 막대 차트 및 7일 복합 차트 유틸리티
├── data/
│   ├── forecast.csv            # 기상 데이터 (기온, 강수량 등)
│   ├── 경매only.csv             # 경매 데이터 원본 (146만 행)
│   ├── 정가수의only.csv         # 정가수의 데이터 원본 (24만 행)
│   ├── daily_auction_summary.parquet   # 일별 요약 초고속 캐시
│   ├── daily_private_summary.parquet   # 정가수의 일별 요약 캐시
│   └── substitute_matrix.parquet       # 4대 대체재 일별 가격 매트릭스 캐시
├── .streamlit/
│   └── config.toml             # Streamlit 헤드리스 및 테마 설정
├── LightBGM경매예측.ipynb        # 원본 경매 노트북
├── LightBGM정가수의예측.ipynb    # 원본 정가수의 노트북
└── README.md                   # 시스템 설명서 및 실행 가이드
```
